# 使用索引

先通过 [OAuth 指南](oauth.md)完成授权，再使用当前包提供的模块入口。通用字段说明见[公共约定](_conventions.md)。

按任务选择 `entries/` 中最具体的入口，再读取入口指向的 reference 或 workflow。以实际安装的命令帮助和本包内容为准；不要根据另一产品的文档推断支持范围。危险写操作先核实用户授权和路径。
